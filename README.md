# PassVault

Офлайн-хранилище и генератор паролей для Windows. Один зашифрованный файл `vault.pmv`,
никаких облаков и аккаунтов. Есть парное приложение для Android
([PassVaultAndroid](https://github.com/Keavors/PassVaultAndroid)) с тем же форматом файла:
синхронизация — перенос файла и слияние с разбором расхождений на любой из сторон.

Текущая версия: 3.4. Подробная история решений и изменений по версиям — в
[README_PassVault.txt](README_PassVault.txt).

## Возможности

- Записи: название, логин, пароль, адрес, заметки; поиск по всем полям; история до 10 прошлых паролей.
- Генератор паролей на криптографическом ГСЧ ОС с настраиваемым набором символов.
- Автосохранение через секунду после правки, атомарная запись с проверкой расшифровкой.
- Четыре слоя защиты от потери данных: корзина, история паролей, архив снимков с ротацией
  «дед-отец-сын» и предыдущая версия файла для мгновенного отката.
- Слияние с другим файлом хранилища: расхождения показываются целиком, удаления переносятся,
  перед слиянием делается снимок, отмена откатывает всё.
- Экспорт и импорт CSV/JSON, понимает выгрузки Bitwarden и KeePass.
- Автоблокировка, очистка буфера обмена через 30 секунд, растущая пауза после неверных паролей.
- Программа не пишет ничего в профиль пользователя: всё лежит рядом с хранилищем.
- Сеть отключается на уровне процесса (`pvault/netblock.py`); гарантию уровня системы даёт
  правило брандмауэра на `GemSwap.exe`.

## Маскировка

Снаружи программа выглядит как головоломка «три в ряд» **Gem Swap**: так называются exe
(`GemSwap.exe`), окно, ярлыки и строка в списке программ, а значок — поле с цветными камнями.
По рабочему столу и панели задач не видно, что внутри пароли. Название задаётся в
`pvault/__init__.py` (`APP_NAME`, `EXE_STEM`), значок рисует `tools/make_icon.py` — он же
обновляет значок Android-версии (`--android`). Внутренние имена (пакет `pvault`, файлы `*.pmv`)
не менялись, поэтому старые хранилища открываются как есть, а установщик, поставленный поверх
прежней версии, убирает старые `PassVault.exe` и ярлыки «PassVault».

## Установка и запуск

**Готовый установщик.** Запустите `GemSwap-Setup-<версия>.exe`: Python не нужен, права
администратора не нужны. По умолчанию ставится на тот диск, с которого запущен установщик.
Удаление — «Параметры → Приложения»; хранилище, откат и архив снимков при этом не удаляются.

**Без установки.** Положите `GemSwap.exe` куда угодно и запустите. Установщик и приложение —
один файл, различаются именем: `GemSwap-Setup-*.exe` ставит, `GemSwap.exe` открывает хранилище.

**Из исходников.**

```bash
pip install cryptography argon2-cffi
python passvault.py
```

Самопроверка: `python passvault.py --test` (автотесты), `GemSwap.exe --selfcheck` (собранный exe).

## Сборка

```bash
python build.py            # ключи: --skip-tests, --clean, --console
```

Скрипт доустановит недостающее (PyInstaller), нарисует иконку, прогонит автотесты и соберёт
в `dist\` установщик `GemSwap-Setup-<версия>.exe` и `GemSwap.exe`. Если тесты не проходят,
сборка останавливается. UPX намеренно отключён: сжатый неподписанный exe ловит ложные
срабатывания антивирусов.

## Где лежат данные

Всё рядом с хранилищем:

| Файл | Что это |
|---|---|
| `vault.pmv` | хранилище |
| `vault.pmv.prev` | предыдущая версия для отката |
| `vault.pmv.lock` | признак «открыто», снимается при выходе |
| `vault.pmv.att` | счётчик неверных паролей |
| `vault_backups\` | архив снимков (папку можно перенести: Инструменты → Настройки) |

Список последних открытых файлов — в `config.json` рядом с программой. Хранилище ищется по
аргументу командной строки, последнему открытому пути, рядом с программой, уровнем выше,
в «Документах» и на рабочем столе.

## Защита

- Мастер-пароль → Argon2id (3 прохода, 256 МиБ, 4 потока), соль 16 байт → ключ AES-256.
- Файл шифруется AES-256-GCM: неверный пароль, повреждение или подмена дают ошибку, а не мусор.
- Числа из заголовка файла проверяются на разумность, чтобы подсунутый файл не заморозил программу.
- Пишется только формат `PMVAULT2` (Argon2id). `PMVAULT1` (PBKDF2, версии 1.x и 2.x) читается
  всегда и при первом открытии сам переезжает на Argon2id, предварительно сняв копию в архив
  в прежнем формате. Мастер-пароль не меняется.
- Открытый текст внутри — JSON UTF-8 (`version`, `entries`, `settings`), метки времени ISO-8601 в UTC.
  Незнакомые поля из более новых версий сохраняются нетронутыми.

## Резервные копии

Снимок делается при сохранении (не чаще раза в 5 минут и только при изменении содержимого),
сразу при открытии, если архив пуст, и перед событиями: слиянием, сменой пароля, восстановлением,
чисткой и импортом. Ротация: последние 12, почасовые за сутки, дневные за месяц, месячные за год,
событийные — последние 10. Восстановление идёт слиянием, а не заменой файла. Снимки — обычные
файлы `.pmv`, их можно открыть через «Открыть другой файл…».

## Синхронизация с телефоном

- ПК → телефон: Файл → «Сохранить копию как…» → файл на телефон → в приложении «⋮» → «Импорт и слияние».
- Телефон → ПК: «⋮» → «Экспорт копии» → файл на ПК → Файл → «Слить с другим файлом…».

Правила слияния одинаковы на обеих сторонах: новые записи добавляются, одинаковые пропускаются,
расхождения показываются с обеими версиями и пометкой «новее», при замене прежний пароль уходит
в историю. Чтобы обе стороны стали одинаковыми: слейте на устройстве А, экспортируйте результат и слейте на Б.

## Горячие клавиши

`Ctrl+S` сохранить, `Ctrl+N` новая запись, `Ctrl+L` заблокировать, `Ctrl+B` резервные копии.

## Устройство кода

```
passvault.py            точка входа
build.py                сборка exe и установщика
pvault/crypto.py        контейнер, KDF, шифрование
pvault/model.py         записи, метки времени, история, надгробия
pvault/generator.py     генератор паролей
pvault/merge.py         слияние
pvault/paths.py         где лежат хранилище и служебные файлы
pvault/storage.py       атомарная запись, замок, поиск копий
pvault/backup.py        архив снимков и ротация
pvault/portable.py      экспорт/импорт CSV и JSON
pvault/throttle.py      задержка после неверных паролей
pvault/config.py        список последних файлов
pvault/session.py       открытое хранилище: сохранение, слияние, пароль
pvault/setup.py         установка и удаление
pvault/netblock.py      отключение сети
pvault/selfcheck.py     самопроверка собранного exe
pvault/ui/              интерфейс (единственный слой, знающий про tkinter)
tests/                  автотесты (193 проверки)
tools/make_icon.py      иконка рисуется кодом
tools/make_android_fixture.py   эталонные файлы для тестов Android-версии
_legacy/                исходники версий 1.x и незаконченной 2.1, старый README
```

Всё, кроме `pvault/ui`, не знает про tkinter и проверяется тестами без единого окна на экране.
Автотесты ничего не пишут в профиль пользователя: временные файлы уходят в `.testtmp` рядом с проектом.

```bash
python -m pytest            # или python passvault.py --test
```

## Совместимость с Android-версией

Проверяется на настоящих файлах в обе стороны. `python tools\make_android_fixture.py` кладёт
в тесты Android-проекта два эталона (`PMVAULT2` и `PMVAULT1`); путь к проекту задаётся переменной
`PASSVAULT_ANDROID_PROJECT`. Android-тест в свою очередь пишет `app\build\interop\android_vault.pmv`,
который читает `tests/test_android_interop.py`; без него эти проверки пропускаются.

Порядок при изменении формата: тесты ПК → `make_android_fixture.py` → `gradlew :app:testDebugUnitTest` → снова тесты ПК.
